# CodeAlpha_Chatbot

A rule-based console chatbot built for the CodeAlpha Python Programming Internship (Task 4).

## Features
- Replies to "hello", "how are you", and "bye" with predefined responses
- Extra replies for "hi", "what is your name", and "help"
- Runs in a loop until the user types "bye"

## How to Run
1. Install Python 3 from python.org
2. Download `chatbot.py`
3. Open a terminal in the file's folder and run:
```
python chatbot.py
```

## Concepts Used
`if-elif`, functions, loops, input/output
